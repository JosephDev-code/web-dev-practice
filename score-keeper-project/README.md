# Score Keeper

A simple two-player score keeping web application built while practicing JavaScript DOM manipulation and event handling.

## Features

- Keep track of scores for two players
- Choose the winning score from 5 to 10
- Increase each player's score with a button
- Automatically detect when a player reaches the winning score
- Highlight the winner and losing player
- Disable the scoring buttons when the game ends
- Change the winning score and start a new game
- Reset the game at any time

## Technologies Used

- HTML
- CSS
- JavaScript
- Bulma CSS Framework

This project was created to practice:

- Conditional statements
- Boolean state management
- Handling user input with `<select>`
- Adding and removing CSS classes

## How It Works

Players can select the score they are playing to and use their respective buttons to increase their scores.

When a player reaches the selected winning score, the game ends. The winner's score is highlighted, the losing player's score is marked differently, and both scoring buttons are disabled.

The **Reset** button clears the current scores and returns the game to its initial state.
