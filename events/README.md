# JavaScript Events Practice

This folder contains exercises focused on handling user events with JavaScript.

## What I Practiced

- Inline event handlers
- `onclick`
- `addEventListener()`
- Double-click events
- The `this` keyword
- Event objects
- Keyboard events
- `keydown`
- `event.code`
- Using `switch` with keyboard events
- Preventing repeated event execution

## Events Practice

The events exercise demonstrates different ways of responding to user interactions, including button clicks, double clicks, and keyboard input.

It also explores the `this` keyword inside event handlers and uses randomly generated RGB colors to change the appearance of buttons when they are clicked.

## Form Practice

The form exercise focuses on working with HTML forms and user input, including text fields, number inputs, buttons, and form submission.

## Technologies

- HTML
- JavaScript
- DOM API

## Purpose

These exercises were created while learning how JavaScript responds to and handles user interactions in the browser.
