# JavaScript Form Practice

This exercise focuses on working with HTML forms and user input using JavaScript.

## What I Practiced

- Selecting form elements
- Working with text inputs
- Working with number inputs
- Handling form submissions
- Accessing user-entered values

## Description

The page contains examples of forms for entering information such as a cat's name and grocery items.

It also includes an input field for entering a username.

## Technologies

- HTML
- JavaScript
- DOM API
