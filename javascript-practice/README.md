# JavaScript Fundamentals Practice

This contains small exercises and practice code created while learning the fundamentals of JavaScript.

## Topics Practiced

The exercises in this repository focus on core JavaScript concepts, including:

- Strings and string methods
- Arrays and array manipulation
- Functions
- Function arguments
- Basic logic and control flow

## Purpose

The goal of this project is to build a strong understanding of JavaScript basics by writing small practice programs and experimenting with different language features.

## Technologies Used

- JavaScript
- Browser Console

## Notes

Most of the practice code was written to run in the browser console using prompts and simple outputs. The exercises are meant for learning and experimentation rather than building full applications.
