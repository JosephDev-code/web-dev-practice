# Web Development Practice

This repository contains various small projects and exercises created while learning the fundamentals of web development.

The goal of this repository is to document my progress as I learn and practice core front-end development concepts.

## Topics Covered

The projects in this repository focus on the following areas:

- HTML structure and page layout
- CSS styling and layout techniques
- CSS selectors and the box model
- CSS hover effects and transforms
- Bootstrap components and layout
- JavaScript fundamentals
- Arrays, strings, functions, and arguments
- Simple JavaScript projects

## Projects Included

### HTML & CSS Practice
Exercises focused on learning CSS selectors, page sections, and basic layout techniques.

### CSS Hover Button
A small project demonstrating a button with a hover effect using CSS styling and transforms.

### Bootstrap Practice
Experiments with Bootstrap components and layout utilities.

### JavaScript Fundamentals
Practice exercises covering core JavaScript concepts such as:
- strings
- arrays
- functions
- arguments

### JavaScript To-Do List (Console Version)
A simple to-do list project built while learning JavaScript fundamentals.
