Fancy Button Hover Effect

This project is a small CSS exercise demonstrating how to style a button and apply hover effects using CSS.

## Description
The page displays a button centered on the screen. When the user hovers over the button, a CSS hover effect is triggered to change its appearance.

## Concepts Practiced
- CSS hover effects
- CSS transform
- Basic page layout
- Styling buttons with CSS

## Technologies Used
- HTML
- CSS

## Purpose
This project was created as part of my learning process while practicing CSS fundamentals.
