# DOM Manipulation Practice

This project is an exercise in manipulating the Document Object Model (DOM) using JavaScript.

## What I Practiced

- Selecting elements from the DOM
- Creating HTML elements with JavaScript
- Adding classes to elements
- Changing element content
- Setting image sources dynamically
- Appending elements to the page
- Using loops to generate content

## Description

The project dynamically creates Pokémon images and their corresponding numbers using JavaScript.

A loop is used to generate Pokémon elements from 1 to 151. Each Pokémon is given an image and a number before being added to the page.

## Technologies

- HTML
- CSS
- JavaScript
- DOM API

## Purpose

This project was created while learning how JavaScript can be used to manipulate and generate content directly on a webpage.
