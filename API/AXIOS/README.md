# Axios API Practice

This exercise focuses on using Axios to make HTTP requests in JavaScript.

## What I Practiced

- Using Axios to make API requests
- Making GET requests
- Working with API responses
- Handling asynchronous operations
- Working with JSON data

## Description

This exercise was created while learning how to communicate with external APIs using Axios.

It is part of my JavaScript API practice, alongside exercises using the Fetch API and XMLHttpRequest.

## Technologies

- HTML
- JavaScript
- Axios

## Purpose

This project was created to understand how Axios can be used to simplify making HTTP requests and working with data returned from an API.
