# XMLHttpRequest Practice

This exercise focuses on using `XMLHttpRequest` to make an HTTP GET request in JavaScript.

## What I Practiced

- Creating an XMLHttpRequest
- Making GET requests
- Handling successful responses
- Handling errors
- Working with JSON data
- Using `JSON.parse()`

## Description

The exercise sends a GET request to the Star Wars API and processes the returned response.

The response is converted from JSON text into a JavaScript object using `JSON.parse()` before being displayed in the console.

## Technologies

- HTML
- JavaScript
- XMLHttpRequest

## Purpose

This was created to understand the traditional XMLHttpRequest approach to making API requests before working more extensively with the Fetch API.
