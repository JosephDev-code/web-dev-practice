# JavaScript APIs Practice

This folder contains practice exercises focused on making HTTP requests in JavaScript and working with external APIs.

## Topics Practiced

- Fetch API
- XMLHttpRequest (XHR)
- Making GET requests
- Handling responses
- Converting JSON responses
- Promises
- Async/await
- Error handling

## Exercises

### Fetch
Practice using the Fetch API to make requests to the Star Wars API. The exercise also demonstrates handling multiple requests in sequence using promises and async/await.

### XMLHttpRequest
Practice making HTTP requests using the older XMLHttpRequest approach and handling the returned response data.

## Purpose

These exercises were created while learning how JavaScript communicates with external APIs and handles asynchronous operations.
