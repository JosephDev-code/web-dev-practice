# Fetch API Practice

This exercise focuses on using the JavaScript Fetch API to make requests to an external API.

## What I Practiced

- Making requests using `fetch()`
- Handling promises with `.then()`
- Converting responses using `.json()`
- Making multiple requests in sequence
- Using `async/await`
- Handling errors with `try/catch`

## Description

The exercise makes requests to the Star Wars API to retrieve information about different characters.

The first version demonstrates handling sequential requests using promise chaining. The exercise then uses `async/await` to make the same process easier to read and understand.

## Technologies

- HTML
- JavaScript
- Fetch API

## Purpose

This was created as part of my practice with asynchronous JavaScript and working with APIs.
