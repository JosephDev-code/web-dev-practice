# JavaScript To-Do List

This project is a simple To-Do List built while learning JavaScript fundamentals.

## Description

The application allows users to manage a list of tasks. Users can add tasks and keep track of items they want to complete.

This project was created as part of my practice while learning JavaScript basics.

## Features

- Add tasks to a list, using the command add
- Display the list of tasks, using the command list
- Delete tasks from the list, using the command delete
- Quit from the prompt interface using the command quit
- Simple styling using CSS and Bootstrap

## Concepts Practiced

- JavaScript arrays
- Functions
- User input
- Basic program logic
- loops

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Purpose

The goal of this project was to practice JavaScript fundamentals and understand how JavaScript interacts with a webpage.
